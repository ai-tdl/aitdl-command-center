Agent Operating Rules
Before executing any task, the AI agent MUST read and follow every rule in this section. These rules exist to guarantee zero disruption to the live aitdl.com product.

RULE 1 — READ BEFORE WRITE


Before creating any file, read whether it already exists. If it does, diff the change — do not overwrite blindly.
Before running any git command, run git status and git log --oneline -5 first. Confirm branch is correct.
Before any Firebase deploy, run firebase functions:list to confirm current state.

RULE 2 — DOUBLE-CHECK PROTOCOL (MANDATORY AFTER EVERY TASK)


After completing each numbered task, the agent MUST execute this exact verification sequence before marking it complete and moving to the next task:

!
If curl returns anything other than 200 after a task — STOP immediately. Do not proceed. Rollback the last change using: git revert HEAD && git push origin main


RULE 3 — NEVER TOUCH MAIN DIRECTLY


All code changes happen in dev or feature branches first.
main branch receives changes ONLY through verified PRs or the mergeBranch() function — never a direct push.
Exception: branch protection rule setup (Task 3, S1) modifies settings only — no code changes.

RULE 4 — ENVIRONMENT VARIABLES ARE NEVER HARDCODED


All secrets go into Firebase environment config: firebase functions:config:set
Dashboard secrets go into .env.local — never committed to git
.gitignore must include: .env.local, .env, serviceAccount.json

RULE 5 — FIREBASE FUNCTIONS DEPLOY IS ISOLATED


Never run firebase deploy — it deploys everything including Hosting.
Always use: firebase deploy --only functions to isolate function deploys.
For Firestore rules: firebase deploy --only firestore:rules

RULE 6 — CONFIRM PREREQUISITES BEFORE EACH SPRINT


Before starting S2 tasks, confirm all S1 tasks pass their double-check.
Before starting S3, confirm S1 + S2 complete. The execution table in Section 4 lists exact prerequisites.
If a prerequisite is not complete, the agent must pause and report which item is blocking.

import * as functions from "firebase-functions";
import * as admin from "firebase-admin";


export const deployLog = functions.https.onRequest(async (req, res) => {
  if (req.method !== "POST") { res.status(405).send("Method Not Allowed"); return; }


  const token = req.headers.authorization?.split("Bearer ")[1];
  if (token !== process.env.FIREBASE_ADMIN_TOKEN) {
    res.status(401).send("Unauthorized"); return;
  }


  const { branch, status, commit } = req.body;
  await admin.firestore().collection("deployments").add({
    branch, status, commit,
    timestamp: admin.firestore.FieldValue.serverTimestamp(),
  });


  res.status(200).json({ ok: true });
});




S1-T5 — functions/src/auth.ts  (CREATE)
functions/src/auth.ts
import * as admin from "firebase-admin";
import * as functions from "firebase-functions";


export async function verifyAdminToken(
  req: functions.https.Request
): Promise<boolean> {
  try {
    const authHeader = req.headers.authorization || "";
    const token = authHeader.startsWith("Bearer ") ? authHeader.split(" ")[1] : null;
    if (!token) return false;
    const decoded = await admin.auth().verifyIdToken(token);
    if (!decoded.admin) return false;
    return true;
  } catch { return false; }
}

functions/src/triggerDeploy.ts
import * as functions from "firebase-functions";
import fetch from "node-fetch";
import { verifyAdminToken } from "./auth";


const GITHUB_TOKEN = process.env.GITHUB_TOKEN!;
const REPO = "ai-tdl/aitdl-command-center";


const workflowMap: Record<string, string> = {
  dev: "dev-preview.yml",
  beta: "beta-preview.yml",
  production: "production.yml",
};


export const triggerDeploy = functions.https.onRequest(async (req, res) => {
  if (!verifyAdminToken(req)) { res.status(401).send("Unauthorized"); return; }


  const { branch } = req.body as { branch: string };
  const workflow = workflowMap[branch];
  if (!workflow) { res.status(400).send("Unknown branch"); return; }


  const response = await fetch(
    `https://api.github.com/repos/${REPO}/actions/workflows/${workflow}/dispatches`,
    { method: "POST", headers: { Authorization: `Bearer ${GITHUB_TOKEN}`, "Content-Type": "application/json" }, body: JSON.stringify({ ref: branch }) }
  );


  if (!response.ok) { res.status(500).json({ error: "GitHub API dispatch failed" }); return; }
  res.status(200).json({ ok: true, branch, workflow });
});

    { method: "POST", headers: { Authorization: `Bearer ${process.env.GITHUB_TOKEN}`, "Content-Type": "application/json" },

  );


  const data = await response.json();
  res.status(response.ok ? 200 : 500).json(data);
});




S2-T7 — functions/src/checkSiteHealth.ts  (CREATE)

import * as functions from "firebase-functions";
import * as admin from "firebase-admin";
import fetch from "node-fetch";


const TARGET_URL = "https://aitdl.com";
const ALERT_THRESHOLD_MS = 2000;


export const checkSiteHealth = functions.pubsub
  .schedule("every 1 minutes")
  .timeZone("Asia/Kolkata")
  .onRun(async () => {
    const startTime = Date.now();
    let status = "online"; let responseTime = -1;


    try {
      const response = await fetch(TARGET_URL, { method: "GET" });
      responseTime = Date.now() - startTime;
      if (!response.ok) status = "degraded";
      if (responseTime > ALERT_THRESHOLD_MS) status = "slow";
    } catch (err) {
      responseTime = Date.now() - startTime;
      status = "offline";
    }


    const db = admin.firestore();
    await db.doc("metrics/latest").set({ status, responseTime,
      timestamp: admin.firestore.FieldValue.serverTimestamp() });
    await db.collection("metrics/history/entries").add({ status, responseTime,
      timestamp: admin.firestore.FieldValue.serverTimestamp() });
  });

rules_version = "2";
service cloud.firestore {
  match /databases/{database}/documents {
    match /metrics/{document=**} {
      allow read: if true;
      allow write: if false;
    }
    match /deployments/{doc} {
      allow read, write: if request.auth != null
                         && request.auth.token.admin == true;
    }
    match /configs/{doc} {
      allow read, write: if request.auth != null
                         && request.auth.token.admin == true;
    }
    match /logs/{doc} {
      allow read, write: if request.auth != null
                         && request.auth.token.admin == true;
    }
  }
}




Future Sprints (S4+) — functions/src/rollbackDeploy.ts  (CREATE IN S4)
functions/src/rollbackDeploy.ts — DO NOT DEPLOY until full pipeline is live (Task 15)
import * as functions from "firebase-functions";
import * as admin from "firebase-admin";
import fetch from "node-fetch";
import { verifyAdminToken } from "./auth";


export const rollbackDeploy = functions.https.onRequest(async (req, res) => {
  if (!verifyAdminToken(req)) { res.status(401).send("Unauthorized"); return; }


  const snap = await admin.firestore().collection("deployments")
    .where("branch", "==", "main").where("status", "==", "success")
    .orderBy("timestamp", "desc").limit(2).get();


  if (snap.size < 2) { res.status(400).send("No previous deploy to rollback to"); return; }


  const previousCommit = snap.docs[1].data().commit;


  await fetch(
    `https://api.github.com/repos/${process.env.REPO}/git/refs/heads/main`,
    { method: "PATCH", headers: { Authorization: `Bearer ${process.env.GITHUB_TOKEN}` },
      body: JSON.stringify({ sha: previousCommit, force: true }) }
  );


  res.status(200).json({ ok: true, rolledBackTo: previousCommit });
});
